# 山海一家會館 Official Site

這是山海一家會館官方網站的獨立專案，已從 ACG / Otaku Match 相關程式分開。

## 內容

- `index.html`: 首頁
- `rooms.html`: 房型
- `booking.html`: 訂房資訊
- `access.html`: 交通資訊
- `xiju-travel.html`: 西莒旅遊
- `faq.html`: 常見問題
- `gallery.html`: 山海影像
- `assets/images/`: 網站圖片素材

## 本機預覽

cd "C:\Users\陳冠霖\Documents\Projects\shan-hai-villa"

```

http://localhost:5500
```

這個網站是純靜態網站，不需要 npm install 或 build。
